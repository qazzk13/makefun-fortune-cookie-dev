One original fortune-cookie line for a software developer, written to `/output/entry.txt` by `main.ts`.

> Every estimate is a fortune told twice: once to the manager, once to the mirror.

The line is 80 characters, a single sentence, and the program is fully deterministic: no network, no model calls, no randomness — every run writes the same bytes.

## Run it

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt`.
